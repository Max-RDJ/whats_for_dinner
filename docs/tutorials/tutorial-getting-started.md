# Getting Started

This tutorial guides you through customising your meal collection and generating a weekly meal plan.

By the end of this guide, you will have:

- Added meals to your collection
- Generated a weekly meal plan
- Viewed the generated results on the home page

---

## Step 1: Open the Application

Open the application in your browser.

The home page page will be displayed by default.

---

## Step 2: Add Your First Meal

Create a new meal entry.

1. Navigate to the Meal Manager by opening the side navigation menu with the hamburger icon in the top left.
2. Select the option to add a new meal.
3. Enter a meal name (for example: "Spaghetti Bolognese").
4. Add a list of ingredients.
5. Click 'Add meal'.

The meal will now appear in your meal collection.

---

## Step 3: Add More Meals

Repeat the process to add several meals.

For example:

- Chicken Curry
    - Chicken breast, tikka massala sauce, rice
- Vegetable Stir Fry
    - Black beans, mushroom, bell pepper, cabbage, spring onion, noodles
- Tacos
    - Beef mince, onion, garlic, salsa, shredded lettuce, tomatoes, cheese

These meals will be used for meal plan generation.

---

## Step 4: Generate a Meal Plan

Navigate to the home page and generate a meal plan using the 'Generate new meal plan' button in the tray at the bottom of the page.

A weekly plan will be created using the meals in your collection.

The generated plan will be displayed on the home page.

---

## Step 5: View Your Meal Plan

The application will display meals assigned to each day of the week.

You can review the generated plan directly on the home page.

---

## Next Steps

You can now:

- Add, edit or remove meals in your collection
- Generate new meal plans
- Export a generated plan and save it to your device
- Import previously exported plans
- Explore the reference documentation to understand feature behaviour
