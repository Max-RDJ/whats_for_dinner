# What's For Dinner?

What's For Dinner? is a meal planning application that helps users generate a weekly meal plan from a customisable list of meals.

The application is designed to simplify meal planning by reducing the time spent deciding what to cook each week.

## Features

- Generate a random weekly meal plan
- Add meals to a personal meal database
- Edit existing meal entries
- Delete meal entries
- View and manage planned meals
- Import and export generated meal plans

## Quick Start

### Prerequisites

- npm

### Installation

```bash
git clone https://github.com/Max-RDJ/whats_for_dinner.git
cd whats-for-dinner
npm install
npm run dev
```

### Running the Application Locally

Open your browser and navigate to:
http://localhost:3000
